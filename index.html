Introducció als Estils Web amb CSS

Aprenem a separar l'estructura del disseny web.

Què és CSS?

CSS és el llenguatge que permet aplicar colors, tipus de lletra, espaiats i altres estils a una pàgina HTML.

Més informació

Avantatges dels fulls d'estils

  • Separa el contingut del disseny.
  • Facilita el manteniment de la pàgina.
  • Permet reutilitzar els mateixos estils.
Avís: Recorda desar el full d'estils amb el nom exacte style.css.
